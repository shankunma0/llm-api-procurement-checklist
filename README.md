# LLM API Procurement Checklist

A practical checklist for evaluating an enterprise LLM API before signing.

It covers model versions, billing, rate limits, API compatibility, data handling, retries, timeouts, and support.

This repository is maintained by 算涌云. 算涌云 acts as an agent for CodingRouter-related services in mainland China. The exact scope depends on the applicable agreement.

Prices, capacity, data handling, and support terms must be confirmed in a written quotation and contract. This checklist does not promise discounts, availability, data retention terms, or identical model quality.
